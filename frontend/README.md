# TodayInfo public frontend — VPS dual-port deployment

This directory contains the public frontend for **https://todayinfo.co.za**.

## Production layout

Keep the whole project in one folder:

```text
/opt/filebrowser/today/
  frontend/       <- public SPA files
  public/admin/   <- admin dashboard files
  src/            <- API + frontend Node servers
  data/           <- local fallback/queues
  uploads/        <- local upload fallback
  deploy/         <- optional service/deployment examples
  .env            <- private production settings
  package.json
```

Production URLs and listeners:

```text
https://todayinfo.co.za            -> 127.0.0.1:3011
https://todayinfo.co.za/admin/     -> 127.0.0.1:3011
https://api.todayinfo.co.za        -> 127.0.0.1:3009
https://api.todayinfo.co.za/api/v1 -> 127.0.0.1:3009
```

Start the two processes:

```bash
npm run start:api
npm run start:frontend
```

The API process uses `PORT=3009`. The frontend/admin process uses `FRONTEND_PORT=3011`.

## SPA routing

The frontend Node server handles extension-free routes itself. Requests such as:

```text
/jobs
/bursaries
/za/jobs/example-role
/za/bursaries/example-bursary
/guides/example-how-to-apply
/admin
```

do not depend on Nginx `try_files` and do not return `Cannot GET`.

## Admin API

The admin UI is served from `todayinfo.co.za/admin`, while authentication and admin actions run on `api.todayinfo.co.za/admin/api`.

The dashboard uses credentialed cross-subdomain requests. The API only accepts admin browser origins listed in:

```env
ADMIN_ALLOWED_ORIGINS=https://todayinfo.co.za,https://www.todayinfo.co.za
```

This keeps CEO login, edit, promote and publish actions working when the UI and API are on separate ports/subdomains.

## Caching

The frontend server uses:

- strong ETags;
- gzip/Brotli-compatible response compression through Express compression;
- one-day browser caching for `/assets/*`;
- stale-while-revalidate for static files;
- no-store for the admin dashboard;
- no-cache for SPA HTML so deployments appear quickly.

The API keeps its existing public cache headers. R2/local published JSON fallback remains unchanged.

## Runtime API configuration

`/data/api-config.js` is generated by the frontend server from the same `.env` file:

```env
PUBLIC_SITE_ORIGIN=https://todayinfo.co.za
PUBLIC_API_ORIGIN=https://api.todayinfo.co.za
```

Local development automatically uses `http://localhost:3009/api/v1`.

## R2

Cloudflare R2 remains TodayInfo's published JSON/file storage layer. Moving the frontend/admin process to port 3011 does **not** change:

- R2 bucket name;
- R2 credentials;
- published JSON object keys;
- publication retry queue;
- Supabase/PostgreSQL tracking.
