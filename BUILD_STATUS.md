Deep-sync and source-memory upgrade.

- Importer supports up to 100 source pages at up to 100 records per page.
- Existing source records are remembered by source key.
- Review/promoted state is preserved on re-fetch; Ignore has been removed.
- Source changes are tracked separately.
- Import cards show fetch count, last seen, source date and quality score.
- Archive/tag/category/pagination pages are filtered before review.
- Cleaning rules remove more crawler boilerplate and duplicate lines.
- Tags/categories are normalized and fallback tags are generated by rules.
- Psychometric-test tag import remains supported.
- Demo/testing deep sync can publish up to three clean preview posts so the public API is immediately visible.
- Duplicate promoted posts are prevented.
- Custom and fetched recommendation links are supported.
- Source related/recommended links are preserved using rule-based filtering.
- Legacy ignored imports are returned to review by migration 003.
- Added incremental migration 002_import_memory.sql.
- Added GitHub Actions CI for syntax + unit tests.

No AI or prediction features were reintroduced.
